# Production Evaluation Plan

The project is no longer gated on a single baseline-vs-treatment experiment. Evaluation happens through repeatable production tasks.

For every task record: model, cost, wall time, render time, repair turns, P0/P1 defects, semantic fidelity and publishability.

Portability is tested across frontier, mid-cost and low-cost models. The target is a stable contract, not identical artistic output.
