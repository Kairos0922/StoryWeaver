# Glossary

| Term | Definition |
|---|---|
| Semantic Model | Structured representation of meaning, entities, relationships, states, and changes contained in source content. |
| Visual Grammar | Reusable mapping from semantic structures to visual representations and animation behaviors. |
| Scene Program | Executable structured description of a video scene, including elements, timing, animation, camera, audio, and captions. |
| Programmatic Video | Video produced from executable or declarative program specifications rather than frame-by-frame manual editing. |
| Deterministic Rendering | Rendering in which the same defined inputs and environment produce reproducible output within the stated reproducibility boundary. |
| Renderer | Component that converts a scene representation into rasterized or encoded media. |
| Visual Primitive | Reusable visual or animation operation such as reveal, transform, highlight, comparison, or process transition. |
| Semantic Primitive | Reusable meaning-level construct such as cause, effect, process, comparison, sequence, state, or hierarchy. |
| Explainer Video | Short-form video whose primary purpose is to communicate or explain structured information. |
