# 发布后指标

模板是 `studio/templates/metrics.md`。一集一份，放在 `series/<series>/epNN/post/metrics.md`。

## 留空是合格的

没有平台导出，这些格子就空着：

- 完播率
- 平均观看时长
- 2s 跳出
- 5s 跳出
- 评论区站队题回复数
- 评论区纠错数
- 评论区「AI 味 / 假声」负面数

不要写「大约」「大概」「预估」「估计」「差不多」「预期」。不要为了表格好看填一个百分比。

EP01 到复盘为止没有这些数。`series/invisible-rules/ep01/post/metrics.md` 保持空白。这不是待办疏忽。

## 有数才填

某一格要填数字，同一行必须有 `来源：` 和具体的后台或文件名，例如：

```text
完播率：31%（来源：抖音创作者后台 2026-10-11 导出）
```

这里的 31% 只是格式例子，不是任何一集的成绩。

`数据来源` 那一行要能指回导出。只写「后台」不够。

返工次数、TTS 字数、重渲次数不是播放成绩。它们可以来自本仓库的闸门记录和配音缓存日志。没有日志就也留空，不要估工时。

## 和下一集的关系

`init-episode` 创建 `ep03` 及以后的目录时，会读上一集的指标。上一集播放格子全空、或数字没有来源，命令失败，错误码 `METRICS_REQUIRED`。

`ep02` 可以创建，因为上一集是 EP01，而且只有 EP01 同时满足这三件事：系列是 `invisible-rules`、文首 `metrics_exception: true`、指标文件里有句子「本集没有可回填的播放数据。留空。禁止估算。」把这句抄到新的一集不会生效。

播放数据回来之后，用它决定下集保留还是丢掉哪一种钩子。决定写在指标文件的最后两行。没有数据，这两行也空着。
