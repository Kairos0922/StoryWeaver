# Visual rhythm

A shot needs one hero move. A hero move is the main change in the frame. Do not add a second move
that competes with it.

## Devices

| Device | Use |
|---|---|
| Kinetic number | One number and one unit |
| Cut | A new angle or a new scale |
| Stamp | A short label or a seal |
| Character action | One clear action |
| Compare bars | Two values on one scale |
| Cards | A short caption or a fact |
| Push | A slow change in scale |
| Pan | A slow change in position |
| Question bubble | A question from the host |

## Rules

- Use at least four named devices in each finished row.
- Use one hero move for each shot.
- Keep text still while the viewer reads it.
- Put a new visual in each 2 to 4 second window.
- Do not use a fade for each element.
- Do not use a bounce or a default slide.
- Do not use a decorative particle.
- Do not put a caption on a face or a hand.
- Keep the caption above the platform controls.

## Beat clock

The beat clock shows a gap when the picture does not change. Add a cue. Do not add a filler
particle. A gap longer than the limit fails the gate.

## Captions

Use two lines at most. Use a large type size. Use a high contrast. Keep a safe margin at the bottom.
