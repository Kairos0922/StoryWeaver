# Product Thesis

> 2026-10-10: series production uses fact cards and Phase A gates. The value equation is unchanged. Rendering stays an adapter. See `docs/studio/migration.md`.

## Core hypothesis

For content with explicit semantic structure, a visual program can communicate relationships more precisely and cheaply than unconstrained pixel generation.

## Value equation

`content value × visual clarity × stability ÷ total production cost`

Total cost includes model tokens, rendering, asset preparation and human correction.

Generated JavaScript is an implementation artifact, not the product boundary.
