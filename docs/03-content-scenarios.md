# Content Scenarios

The initial scenario set is evidence-led.

| Family | Evidence signal | Programmatic advantage | V1 |
|---|---|---|---|
| Music / lyric | multiple Opus 5.5 public examples and Japanese reproduction | exact timing, typography, reusable motion | Yes |
| Product / SaaS | Japanese analysis identifies product/LP/service-demo uses | exact UI/text, editable brand motion | Yes |
| Knowledge / explainer | Japanese tests cover ecology, history and diagrams | causal diagrams and state animation | Yes |
| Data visualization | code media preserves numeric geometry and labels | deterministic charts | Yes |
| History / story | Japanese experimentation with historical explanation | timelines, maps, state transitions | Yes |
| Generative art | many public demos | technically strong | Secondary |

This establishes candidate production families, not guaranteed audience performance.
