# Content Scenarios

The scenario model is organized around viewer value + visual structure, not merely subject matter.

Public Opus 5.5 examples show recurring artifact patterns: narrative animation, music/art hybrids, pixel or riso-like visual language, product/launch videos, and explanatory visuals. The strongest public examples are finished artifacts rather than benchmark screenshots. | Family | Core viewer value | Programmatic advantage | V1 |
|---|---|---|---|
| Visual narrative | story, emotion, reveal | recurring characters, state, scene transitions | **Yes** |
| Lyric / music visual | rhythm + visual payoff | beat timing, typography, procedural motion | **Yes** |
| Knowledge / explainer | understand a mechanism | diagrams, transformations, causal motion | **Yes** |
| Product / SaaS | see a workflow/outcome | exact UI, state transitions, editable copy | **Yes** |
| Data story | notice a trend | exact values, chart geometry, annotations | **Yes** |
| Process / tutorial | follow ordered steps | persistent layout + state changes | **Yes** |
| Comparison | understand trade-offs | synchronized side-by-side geometry | **Yes** |
| History / story | follow time + place | timelines, maps, state transitions | **Yes** |
| Generative art | aesthetic novelty | procedural style and motion | Secondary |
| Photorealistic / cinematic | natural performance | weak fit for deterministic primitives | Excluded |

## Production priority

V1 should prove five reusable visual capabilities rather than ten unrelated templates:

1. Narrative beat: hook → escalation/reveal → payoff.
2. Persistent motif: the same character/object remains structurally stable across scenes.
3. Visual transformation: one state becomes another instead of cutting between unrelated pictures.
4. Rhythmic motion: timed entrances, exits, emphasis and typography.
5. Information graphics: exact labels, charts, diagrams and annotations.

These capabilities cover the high-value production families above.

## Evidence interpretation

A high-engagement X post is evidence that a specific artifact attracted attention; it is not evidence that the underlying format will automatically work on a self-media platform. StoryWeaver therefore uses the research to select capabilities and production hypotheses, not to hard-code a content niche.
