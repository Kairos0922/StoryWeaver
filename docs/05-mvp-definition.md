# V1 Scope

## Included

- renderer-neutral VideoSpec
- deterministic SVG renderer
- resvg-based SVG rasterization
- captions and optional audio mux
- semantic beats and deterministic motion
- validation and CI
- production task library
- evidence-backed scenario coverage
- renderer boundary that permits future Motion Canvas / p5.js / PixiJS adapters

## Excluded

- photorealistic generation
- online editor
- provider-specific model integration
- automatic publishing to social platforms
- unrestricted 3D/cinematic generation
- browser dependency in the default render path
- p5.js / PixiJS / Motion Canvas as V1 runtime dependencies
