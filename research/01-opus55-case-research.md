## Code animation in minutes

Tak published an Oktoberfest code animation and reported a one-shot creation time of 14m48s. This supports fast iteration as a production signal, not a quality guarantee.

Source: https://note.com/kawakijourney_ai/n/nca27c8dbb7e5

## Pixel / deterministic specification

A public example specifies fixed logical resolution, limited palette, fixed timestep, particle pooling and an explicit state machine. This is evidence that precise constraints can shape stable programmatic output.

Source: https://zenn.dev/peoplex_blog/articles/1bc5c181ad19f0

## Research conclusion

The strongest common signal is not “AI can make pretty videos.” It is that programmatic media is attractive where creators need exact text, repeatable geometry, synchronized timing, editable motion and cheap revision. The initial production set therefore covers music/lyrics, product explanation, knowledge explanation, data visualization and history/story.
