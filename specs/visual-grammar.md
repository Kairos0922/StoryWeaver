# Visual Grammar

| Semantic relationship | Encoding | Motion purpose |
|---|---|---|
| sequence | timeline / step flow | reveal order |
| cause → effect | directed arrow / transformation | make causality visible |
| comparison | synchronized side-by-side | expose difference |
| quantity change | bar/line chart | reveal magnitude |
| hierarchy | nested/grouped layout | expose levels |
| state change | same object, changed state | show transition |
| spatial relation | map/diagram/camera | preserve geometry |
| concept → example | abstraction → concrete | ground meaning |
| lyric / narration | timed typography + synchronized motion | reinforce rhythm |
| product feature | UI state transition | demonstrate behavior |

Motion is justified only when it changes attention, reveals a relationship, encodes time, or creates a deliberate narrative beat.
