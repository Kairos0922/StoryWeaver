# AGENTS.md

## Mission

Build StoryWeaver as a production tool for real self-media publishing. Do not optimize for impressive demos that do not survive repeated production.

## Rules

1. Content value precedes implementation convenience.
2. Material claims require evidence or an explicit hypothesis label.
3. Model output is untrusted input: validate before compile/render.
4. Rendering is deterministic and independent of model provider.
5. Prefer constrained structured edits over whole-video regeneration.
6. Do not add features without a measurable quality, stability, cost, or production-time benefit.
7. Keep schemas backward-compatible or document migrations.
8. Keep research, observations, hypotheses and decisions distinct.
9. Use `AGENTS.md` exactly; do not create `Agents.md`.
10. Direct changes to `main` are acceptable; CI must pass before delivery is declared complete.

## Acceptance

A change is complete only when automated checks pass and the documented quality gate is satisfied.
