# Experiment 001 — Baseline Prompt

Use the following prompt with a general coding agent.

> Create a 45–60 second 1280×720 educational explainer video from the supplied source text.
>
> Use Remotion as the renderer. Use simple deterministic vector/text/chart primitives where practical. Include narration, synchronized captions, scene transitions, and readable visual explanations.
>
> You may decide the scene structure, visual composition, animation, and timing yourself. Do not use a predefined StoryWeaver semantic model or visual grammar.
>
> Produce the complete renderable implementation and explain the scene structure briefly.
>
> Source material: `experiments/001-source.md`
