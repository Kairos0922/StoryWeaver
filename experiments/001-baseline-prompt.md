# Experiment 001 — Baseline Prompt

Use the following prompt with the same coding agent/model and renderer as the treatment.

> Create a 45–60 second 1280×720 educational explainer video from `experiments/001-source.md`.
>
> Use Remotion as the renderer. Use simple deterministic vector/text/chart primitives where practical. Include visual explanations, scene transitions, and readable captions.
>
> **Narration and captions are fixed experimental inputs. Do not rewrite, summarize, reorder, or regenerate the narration. Use the fixed narration script in the source verbatim and derive captions from that same script.**
>
> You may decide the scene structure, visual composition, animation, and timing yourself. Do not use a predefined StoryWeaver semantic model, visual grammar, or scene-program schema.
>
> Produce the complete renderable implementation. Do not spend effort on a custom rendering engine or unrelated infrastructure.
