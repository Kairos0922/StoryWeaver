# StoryWeaver Method Proof

This experiment verifies the production method, not maximum visual polish.

Artifacts:
- director-brief.md
- style-guide.md
- beat-sheet.md
- shot-list.md
- revision-0.json
- critique.md
- revision-1.json

Required loop:
Reference → plan → executable spec → render → inspect → critique → structured repair → rerender.

The proof passes only when both specs validate, both renders are generated, and revision 1 contains explicit causal/action improvements over revision 0.
