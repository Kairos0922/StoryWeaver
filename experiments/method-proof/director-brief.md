# Method Proof — Director Brief

Goal: prove a model-agnostic production loop on a 12-second narrative micro-story.

Viewer promise: a paper boat starts still, catches a gust, nearly tips, then reaches a puddle and floats.

Constraints:
- 12 seconds, 16:9
- one recurring protagonist: paper boat
- one recurring environment: puddle
- clear beginning → complication → payoff
- every major action causes the next action
- no decorative motion without narrative purpose
- stable visual identity across shots

Workflow:
Reference → Style Guide → Beat Sheet → Shot List → VideoSpec → Render → Contact Sheet → Critique → Revision → Render

The model/provider is replaceable. The production contract is not.
