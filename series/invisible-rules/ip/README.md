# 角色

三个人跨集复用。分工来自 EP01 剧本和复盘：

| 名字 | 作用 |
|---|---|
| 等等 | 嘴替。提问、犯错、不服。被说服前要停一下 |
| 阿规 | 讲规则。不念「第一、第二、第三」 |
| 嘀嗒 | 报数。一次只报一个数 |

生产环境里，角色由参数化 SVG 经 `build_sprites.py` 生成精灵，复盘记录为 36 个精灵键。精灵文件和 `ip/src/chars.py` 没有移植到本仓库。不要自己编一套表情文件名来假装已经接上。

表情枚举在精灵回到仓库之后冻结。在那之前，Phase A 的「角色动作」用中文写可见动作（按键、挡手、看表、脸垮），不要写未定义的表情 id。

新增第四个角色之前先改系列说明。不要在单集脚本里临时加一个旁白人格。
